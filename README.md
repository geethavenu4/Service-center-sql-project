# Service-center-sql-project
SQL project for service center operations and analytics
This project is a Service Center Management System built using SQL.
It is designed to manage customers, devices, service requests, technicians, and billing details efficiently.
The main goal of this project is to demonstrate database design, SQL queries, and data handling skills suitable for a Data Analyst / SQL fresher role.
---
🛠️ **TECHNOLOGIES USED **
Database: MySQL
Language: SQL
Tool: MySQL Workbench / Any SQL Client
Version Control: GitHub
---
📂 DATA BASE STRUCTURE..........
The project consists of the following tables:
1.customers – Stores customer details
2.devices – Stores device information linked to customers
3.service_requests – Tracks service complaints and status
4.technicians – Stores technician details
5.billing – Manages service charges and payment status
---
🔑**** Key features*****
***Proper use of Primary Keys and Foreign Keys

Use of CRUD operations (INSERT, SELECT, UPDATE, DELETE)
Data filtering using WHERE, GROUP BY, HAVING
Usage of aggregate functions
Real-world service center use case
